# open-audio-player

A fully featured music player with support for local music, podcasts, live radio, and streaming services. It is designed to be lightweight, fast, amazing UI and user-friendly.

## Features

- Local Music discovery (Selected folders)
- Library manager
- Favorites
- Podcast support
- Live/internet radio discovery and playback
- Streaming services: YouTube Music search, account connection, playback and playlist synchronization; direct internet audio streams.
- Logos,artworks support
- Session persistence: resume where left off
- Mpris integration
- Systray (play in background)
- Lyrics support
- waveform visualization
- Amazing ui
	- Mini mode widget
	- Blending background artwork
- Any other relevant music player features

## Hard Requirements

- smooth and fast, great UX
- Platform: Linux
- Packing format: deb, rpm, arch, appimage
- Programming language: Rust
- GUI framework: GTK
- ui files instead of code for easy maintenance
- i18n: english, french, spanish, german, italian, portuguese, russian, chinese, japanese, korean
- docker, devcontainer for development and testing
- avoid unnecessary explanation paragraph in the UI

## Brainstorming

There are many music players out there, but most of them are either too heavy, too slow, or lack features (background playback, podcast support etc...). This project aims to fill that gap by providing a fully featured, fast, and feature-rich music player that is easy to use and maintain.
